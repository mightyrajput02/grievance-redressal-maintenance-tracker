# Grievance Redressal and Maintenance Tracker

## Problem Statement

Managing complaints and maintenance requests manually is slow, inefficient, and lacks transparency.

## Solution

Our platform allows users to:

- Register complaints
- Track complaint status
- Assign maintenance staff
- Receive notifications
- View analytics dashboard
- AI-based complaint categorization

## Tech Stack

Frontend:
- React
- Tailwind CSS

Backend:
- FastAPI / Flask

Database:
- PostgreSQL

AI:
- Python
- NLP

## Features

- User Login
- Admin Dashboard
- Complaint Tracking
- Priority Detection
- Image Upload
- Email Notifications
- Analytics
